## "Unsloppable" Senate
### author: majukemajuan49

The Imperial Senate recently deployed a new authorization system to protect access to restricted government records.

The Empire claims the system is secure because administrative roles are never approved directly.

Several public terminals have been made available for testing, each providing access to a different part of the system.

The engineers insist that becoming an "ImperialAdministrator" is impossible.

Can you prove them wrong?
